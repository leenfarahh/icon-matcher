# Fonts

Figtree, the brand's functional typeface, as variable WOFF2 files (Latin and Latin Extended),
the same files Image Studio self-hosts. Served at `/fonts/<file>` by the connector and the test UI, so the page and the
Claude panel never load fonts from a third party.
